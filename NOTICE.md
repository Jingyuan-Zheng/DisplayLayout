# Notice

Display Layout is a minimal macOS utility created for the requested two-display workflow.
Its design was informed by the open-source DisplayAlign project by Sven Kanoldt
(https://github.com/sassman/display-align), which is licensed under the MIT License.
See `LICENSE-DISPLAYALIGN`.

This package intentionally excludes DisplayAlign's menu bar residency, login item,
configuration/profile system, auto-apply-on-connect behavior, and other background logic.
